# 측정 결과

마일스톤마다 `M<N>/`에 `runs.csv`(실행 하나당 한 행), `summary.csv`(조건당 한 행, 3회 중앙값과 범위), `axes/`(보조 축), `shots/`(대표 스크린샷)를 둔다. 열 이름과 순서는 `schema.md`에 한 번 정하고 모든 마일스톤이 같게 쓴다. 프레임 단위 원본 CSV, 트레이스, 영상은 저장소 밖(`Saved/`)에 두고 라벨만 적는다. 규약은 [Docs/Guides/measurement.md](../Docs/Guides/measurement.md).

`schema.md`는 M0에서 `Scripts/summarize.py`와 함께 만든다.

# ADR-0003 카메라 프리셋을 오브 시점과 탑뷰 둘로 줄인다

- 상태: 승인됨(2026-11-07 채팅에서 사용자가 결정)
- 날짜: 2026-11-07
- 대체: [ADR 이전 결정](README.md) "카메라"(고정 프리셋 3종 궤도 / 탑뷰 / 지상)

## 맥락

계획 단계에서 프리셋 셋에 역할을 정했다. P1 궤도(혼합 대표), P2 탑뷰(원거리 밴드 대조군), P3 지상(근거리 액터 대조군). M0 시나리오를 화면으로 검토하면서 P1을 오브 바깥 궤도에서 "오브 뒤에서 오브 너머 바깥을 보며 1rpm으로 도는" 구도로 바꿨다. 이 구도는 발밑 근거리 액터부터 지평선 원거리까지 한 화면에 담는다. 그러자 P3(오브 뒤 지상 고정)는 P1과 보이는 밴드가 거의 같아졌다.

## 결정

프리셋은 P1 오브 시점(대표)과 P2 탑뷰(원거리 밴드 대조군) 둘이다. P3를 뺀다. 근거리 액터 티어가 주 관찰점인 M3는 P1으로 본다.

## 고려한 대안

| 대안 | 버린 이유 |
| --- | --- |
| P3 유지(오브 뒤 5m 높이 고정) | P1과 밴드 분포가 겹쳐 대조군 역할이 약하다. 측정 시간만 1.5배 |
| P3를 맵 가장자리에서 오브를 보는 구도로 | 원거리 밴드 위주라 P2와 겹친다 |

## 결과

- 전수 매트릭스가 N × 2 프리셋 × 3회가 된다(M1\~M5 N 4개면 24회 × 90초 ≈ 36분).
- 코드: `FLabConfig::Preset`는 1\~2, `run-dev.ps1`·`run-bench.ps1`의 `-Preset`은 `P1`·`P2`만 받는다.

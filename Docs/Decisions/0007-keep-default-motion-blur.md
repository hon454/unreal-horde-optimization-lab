# ADR-0007 ISKM 모션 블러 줄무늬가 있어도 모션 블러는 엔진 기본값(켬)으로 둔다

- 상태: 승인됨(2026-11-11 채팅에서 사용자가 승인)
- 날짜: 2026-11-11

평지 총괄 묶음을 앞두고, 개발 빌드에서 ISKM 미니언 일부가 한 프레임씩 세로로 번지는 모션 블러 줄무늬가 발견됐다. 모션 블러를 끄면 줄무늬는 사라지지만 측정 조건이 엔진 기본과 달라지고 원인은 가려진다. 그래서 모션 블러를 끄지 않고 엔진 기본값으로 두기로 했다. 끄는 안(A)과 엔진 경로를 지금 고치는 안(B)은 버렸다. 이렇게 하면 측정 조건이 엔진 기본 그대로 남고, 글이 따로 설명할 것도 늘지 않는다. 대신 개발 빌드 영상에 줄무늬가 남을 수 있다.

## 맥락

화면 검토에서 사용자가 "미니언 전체가 가끔 번쩍인다"고 보고했다. 진단 세션이 원인을 찾았다([Worklog/M5.md](../Worklog/M5.md) "미니언 깜빡임 진단", 커밋 84c63ac).

| 사실 | 근거 |
| --- | --- |
| 번쩍임은 모션 블러가 일부 미니언의 잘못된 세로 모션 벡터를 그린 것이다. 하늘·바닥·오브는 변하지 않는다 | 연속 캡처 휘도, 속도 버퍼 시각화(`Measurements/M5/shots/flicker_m5bounds_velocity_f3943.jpg`) |
| `r.MotionBlurQuality 0`이면 튀는 프레임이 27개에서 0개가 된다. Budget·Simulation LOD·바운드 고정은 원인이 아니다 | 같은 절 "하나씩 끈 결과" |
| 뚜렷한 것은 ISKM이다. VAT(`m4offpool`)에서는 데이터로 잡히지 않았다 | 같은 절 |
| Lab 프로세서가 넘기는 `PrevTransform`은 정상이다(130초 동안 1m 넘게 어긋난 경우 0건). 엔진 경로(`MassVisualizationComponent.cpp:716-838`)를 의심하지만 확인하지 않았다 | 같은 절 "원인 판단" |
| 37\~66초 게임 시각에만 나고, 카메라 두 번째 바퀴에서는 나지 않는다. 이유는 모른다 | 같은 절 |
| 현상은 화질 문제다. 프레임 비용은 모션 블러 패스 자체의 비용 말고는 바뀌지 않는다 | 계산이 아니라 판단. 모션 블러 패스 비용은 재지 않았다 |

## 결정

모션 블러를 엔진 기본값(켬) 그대로 두고, 평지 총괄 묶음을 그 조건에서 잰다. 줄무늬는 고치지 않는다. 대신 다음과 같이 다룬다.

- 엔진 경로를 찾아 고치는 일은 [backlog.md](../backlog.md) "선택 심화"에 둔다.
- 글 07(ISKM)에 개발 빌드에서 관찰한 현상과 "원인 미확정"을 적는다([post-material.md](../post-material.md) "07").
- 글 영상에서 줄무늬가 거슬릴 때만 촬영 실행에 `r.MotionBlurQuality 0`을 준다. 캡션에 그렇게 적는다. 측정 실행에는 주지 않는다.

## 고려한 대안

| 대안 | 버린 이유 |
| --- | --- |
| A. 모든 단계에서 모션 블러를 끈다(`r.MotionBlurQuality=0`) | 현업에서는 화면 전체의 모션 블러를 꺼서 이런 버그를 해결하지 않는다(기본은 켜고 옵션으로 끈다). 측정 조건이 엔진 기본과 달라져 글마다 설명이 늘어난다. 원인을 확정하지 않은 채 증상만 가린다 |
| B. 엔진 경로를 지금 찾아 고친다 | 소스 추적과 엔진 패치가 필요할 수 있어 작업량을 예측할 수 없다. 글 공개(2026-11-11 사용자 결정: 글 공개 우선)가 늦어진다. 수치에는 거의 영향이 없어 총괄 묶음 전에 고칠 이유가 약하다 |

## 결과

- 평지 총괄 묶음과 글 00\~08의 수치는 모션 블러를 켠 조건이다. [measurement.md](../Guides/measurement.md) "렌더 고정"에 적었다.
- 정지 화면에서는 줄무늬가 거의 잡히지 않는다. 37\~66초 사이에 초당 한두 프레임만 튄다. 영상에서는 보일 수 있다.
- 다시 볼 조건: 엔진 경로를 확인해 원인을 찾았을 때. 또는 줄무늬가 측정 실행의 프레임 값에 영향을 준다는 근거가 나왔을 때. 그때는 이 ADR을 대체한다.

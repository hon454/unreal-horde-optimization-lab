# ADR-0019 단계 8은 액터 상한 1,000·전환 거리 40m를 그대로 두고 액터 메시에 고정 바운드를 쓴다

- 상태: 승인됨(2026-11-15 채팅에서 사용자가 승인. W11 작업 세션 초안. [ADR-0010](0010-final-representation-bands.md)을 잇는다. 대체하지 않는다)
- 날짜: 2026-11-15

`v2`에서 모든 단계가 겹침 방지와 액터 캡슐을 갖게 되자 단계 8(최종 구성)의 프레임 p95가 목표 16.7ms에 0.7ms 남짓까지 다가갔다. W11에서 액터 비용을 줄이는 후보 둘을 재고, 그 결과로 액터 상한과 전환 거리를 다시 쟀다. 하이드레이션 액터 메시의 바운드를 피직스 에셋 대신 에셋의 고정 바운드로 셈하면 프레임 p50이 약 0.7ms 줄고 소형 액터의 애니 건너뜀이 사라진다. 그래서 단계 8에 이것을 켠다. 그래도 전환 거리를 42m로 늘리면 p95가 16.32ms로 편차 여유를 지키지 못한다. 그래서 ADR-0010의 값(상한 1,000, 40m, 80m 밖 그림자 끔)을 그대로 둔다. QueryOnly 바디를 물리 가속 구조의 따로 된 칸에 넣는 CVar는 실행 간 범위 안이라 켜지 않는다.

## 결정

1. 단계 8의 하이드레이션 액터 메시는 `bComponentUseFixedSkelBounds`를 켜고 `BoundsScale` 1.1을 곱한다(`FLabQuality::FixedSkelBoundsScale`). 스위치는 `-LabFixedSkelBounds`이고 단계 1\~7은 끔이다. 메타데이터는 `LabFixedSkelBounds`, 빼 보기 행은 `a8fsb`다.
2. 단계 8의 액터 상한 1,000, 화면 안 전환 거리 40m, 80m 밖 인스턴스 그림자 끔은 그대로다(ADR-0010 결정 1·2).
3. 목표를 지킨다는 판정은 "단계 8의 프레임 p95 중앙값 + 0.6ms ≤ 16.7ms"다. 0.6ms는 지금까지 본 긴 실행이 그 묶음 중앙값보다 길었던 최대 폭이다.
4. `p.Chaos.AccelerationStructureIsolateQueryOnlyObjects`는 엔진 기본값(0)으로 둔다. 스위치 `-LabQueryIsolate`와 하위 실험 `s8iso`만 남긴다.
5. 캡슐을 물리 바디 없는 Lab 판정으로 바꾸는 안은 쓰지 않는다. 사양 3절 기능 3("가까운 개체는 캡슐 콜리전을 가진다")의 뜻이 바뀐다.

## 고려한 대안

| 대안 | 버린 이유 |
| --- | --- |
| A. 전환 거리 42m(고정 바운드 켬) | p95 16.32ms. 목표 안이지만 긴 실행(+0.6ms)이 나오면 16.7ms를 넘는다. 늘어나는 액터는 평균 24개(4%)다 |
| B. 전환 거리 45m | p95 16.96ms로 목표 밖이다 |
| C. 전환 거리 41m | 재지 않았다. 40→42m의 p95 기울기(0.36ms/m)로 보면 16.0ms 안팎이라 여유가 0.1ms 남짓이다. 늘어나는 액터는 평균 약 12개다 |
| D. 액터 상한을 바꾼다(750, 1,250) | 40m에서 상한에 닿지 않는다(최대 794). 750은 품질을 낮추고 1,250은 1만에서 아무것도 바꾸지 않는다 |
| E. 고정 바운드를 배율 없이 쓴다 | p50 이득은 같지만 바운드가 작아 LOD가 거칠어지고(예측 LOD 평균 +0.06\~0.13) 쓰러지는 몸이 상자 밖으로 나갈 수 있다 |
| F. 고정 바운드를 액터가 있는 단계 2부터 켠다 | 같은 일을 더 싸게 하는 것이라 뜻은 맞다. 단계 2(엔진 기본 경로)가 엔진 기본값이 아니게 되고 단계 2\~7을 다시 재야 한다 |
| G. QueryOnly 칸 나누기를 켠다 | 이득이 실행 간 범위 안이다 |
| H. 캡슐을 물리 바디 없는 선분·캡슐 판정으로 바꾼다 | 캡슐 비용 약 2.3ms를 거의 없앨 수 있지만 사양의 기능 3이 바뀐다(결정 5) |

## 결과

- 단계 8의 프레임 p95 여유가 1.10ms다(15.60ms, `V2W11Sweep`). 판정식(결정 3)으로 0.5ms가 남는다. 뒤의 작업이 게임 스레드 일을 더하면 이 0.5ms에서 쓴다.
- 단계 7→8은 품질 올리기(상한·거리·그림자)와 액터 비용 줄이기(고정 바운드)를 함께 담는다. 고정 바운드의 이점은 빼 보기 행 `a8fsb`로 따로 보인다.
- 소형 액터의 애니 갱신을 건너뛰지 않는다(건너뜀 비율 0.12 → 0).
- 바운드 배율 1.1은 죽는 소형의 피직스 에셋 바운드 평균에 맞춘 값이다. 쓰러지는 자세가 화면 가장자리에서 잘리는지는 화면으로 보지 않았다.
- 다시 볼 조건: 단계 8의 p95가 16.1ms를 넘을 때(상한·거리를 낮춘다), 또는 게임 스레드 일이 줄어 여유가 1ms 넘게 늘 때(41\~42m를 다시 잰다).

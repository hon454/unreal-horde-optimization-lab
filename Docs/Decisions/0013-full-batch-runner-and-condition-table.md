# ADR-0013 총괄 묶음은 새 러너로 돌리고 조건 표에는 단계별 기술과 성능 변화만 둔다

- 상태: 승인됨(2026-11-12 채팅에서 사용자가 승인)
- 날짜: 2026-11-12

총괄 묶음 `Full1`은 `run-bench.ps1`을 거치지 않는 새 러너 `Scripts/run-full.ps1`이 돌리고, 조건과 기대 메타데이터는 `Scripts/full-conditions.json` 하나에 둔다. 조건 표에는 최종 독자가 볼 것만 넣는다: 사다리 여덟 단계, 빼 보기 열 행, 하위 실험 셋(21개). 탐색 과정의 이웃 점과 옛 최종값은 표에서 빼고 Worklog의 경위로만 남긴다. 대신 "왜 40m인가" 같은 물음의 근거는 표의 다른 열(사다리 7·8단계의 애니 건너뜀 비율)로 읽어야 한다.

## 맥락

[ADR-0006](0006-three-measurement-tiers.md)의 총괄 묶음은 전 단계와 글이 쓰는 모든 점을 한 날 잰다. Q5에서 러너를 만들며 코디네이터가 구조를 정했고(자율 결정 D16), 사용자가 조건 표의 범위를 정했다(D19).

| 사실 | 근거 |
| --- | --- |
| `run-bench.ps1`은 고치지 않는 파일이고 새 변형 이름(`q2crowd`, `q4final`)과 라벨 형식 `Full1-<단계>-<변형>-N<수>-<프리셋>-r<회차>`를 받지 못한다 | 사용자 지시, [plan.md](../plan.md) "총괄 묶음 러너" |
| 조건 26개일 때 표에는 전환 거리 이웃 점(`S8-h30`·`S8-h50`·`S8-h79`)과 입자 방식 비교(`S8-fxent`·`S8-fariskm`)가 있었다 | [Worklog/Q5.md](../Worklog/Q5.md) |
| 묶음은 178회에 약 4.5\~5.3시간이다 | `run-full.ps1 -DryRun` |

## 결정

1. `Scripts/run-full.ps1`이 패키지 exe를 직접 부른다. `run-bench.ps1`의 절차(앞 창 검사, 첫 실행 `r0` 버리기, 같은 라벨 거부)는 옮겨 쓴다.
2. 회차를 바깥 루프로 돈다(r1 전 조건 → r2 → r3, 짝수 회차는 역순). 몇 시간짜리 묶음의 표류가 조건마다 고르게 퍼진다.
3. 조건, 인자 줄, 기대 메타데이터는 `Scripts/full-conditions.json` 한 곳에 둔다.
4. 조건 표는 21개다: 사다리 `L1`\~`L8`, 빼 보기 `A8-*` 열 행, 하위 실험 `S1-budget`·`S1-uro`·`S8-col`.
5. 탐색의 흔적은 표에 넣지 않는다. 전환 거리 이웃 점과 옛 최종값 79m, 입자 방식 비교 조건을 뺐다. Niagara 대 ISKM은 `L8` 대 `A8-farcull`로 읽는다.
6. 공개 자료(글, README)의 표도 같은 기준으로 만든다. 탐색 경위는 Worklog에 둔다.

## 고려한 대안

| 대안 | 버린 이유 |
| --- | --- |
| `run-bench.ps1 -ExtraArgs`로 감싸기 | 라벨이 계획의 형식과 달라지고 변형 이름이 `m5bounds`로 남는다 |
| `run-bench.ps1`의 변형 목록에 이름 더하기 | 고치지 않기로 한 파일이다 |
| 조건을 바깥 루프로(조건마다 3회 연달아) | 묶음 앞뒤의 표류가 조건 사이 차이로 읽힌다 |
| 조건 26개 유지 | 79m는 "밴드 80m를 넘지 않는 최댓값"이라는 탐색의 흔적이라 표에 나오면 따로 설명이 필요하다. 묶음도 길어진다 |
| 원거리 그림자와 입자 그림자의 2×2 | 독자가 볼 기술은 "원거리 그림자 끔" 하나다 |

## 결과

- 예행 `Reh2`(10초 1회씩)에서 메타데이터 대조, 동등성 검사, 스파이크 검사가 통과했다. 액터 1만 조건 여섯은 10초 구간에서 프레임 수 검사(100 이상)에 걸렸고 60초 구간은 `Full1` 첫 실행으로 확인한다([Worklog/Q5.md](../Worklog/Q5.md) "예행 묶음 Reh2").
- 규약은 [measurement.md](../Guides/measurement.md) "총괄 묶음 `Full1` 규약"에 있다.
- 실행에서 확인한 것은 `Full1` 뒤에 덧붙인다.

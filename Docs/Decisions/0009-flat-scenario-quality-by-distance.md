# ADR-0009 평지 시나리오로 돌아가 목표 사양 안에서 거리별 품질을 확보한다

- 상태: 대체됨 → [0017](0017-roaming-orb-and-equal-function-ladder.md)(`v2` 브랜치에서. main의 `v1`에는 이 결정이 유효하다)
- 날짜: 2026-11-11

[ADR-0008](0008-game-scene-baseline-and-target-spec.md)의 게임 장면(건물, 방향장, 시야 검사 저격, 비켜 가기, 콜리전, 부위 판정, 래그돌)을 버리고 옛 평지 시나리오로 돌아간다. 목표 사양(호드 총수 1만 잠정, 60fps)과 주 지표(목표 총수에서의 프레임 시간)는 유지한다. 프로젝트의 중심은 목표 사양 안에서 거리별로 품질을 확보하는 것이다: 가까이는 액터 하이드레이션, 멀리는 ISKM, 그리는 끝 밖은 Niagara 배경 무리. 최종 구성에 들어가는 기법은 모두 총괄 묶음에서 이점이 측정으로 보여야 한다. 이렇게 하면 구현이 줄고 주제가 하나로 모인다. 대신 글의 장면은 평지이고, 그것을 한계가 아니라 프로젝트의 목적으로 적는다.

## 맥락

ADR-0008을 승인한 날 G1(건물, 방향장, 시야 검사 저격, 비켜 가기)의 구현이 진행됐다. 사용자는 건물과 방향장이 들어가는 것을 보고 과하다고 판단했고, 이 레포의 중심을 액터 하이드레이션과 품질 확보에 두기로 했다.

| 사실 | 근거 |
| --- | --- |
| G1 구현은 커밋하지 않고 버렸다. 코드는 태그 `M5` 뒤의 평지 상태다 | [Worklog/G1.md](../Worklog/G1.md) "중단과 폐기" |
| 평지 시나리오와 측정 인프라는 [ADR-0002](0002-freeze-measurement-infra.md)가 동결했다 | [measurement.md](../Guides/measurement.md) "확정값" |
| 평지에서 60fps를 지키는 최대 N은 액터 813, 로직을 Mass로 옮긴 단계 20,577이다(마일스톤 묶음, P1). 목표 총수 1만은 둘째 단계에서 달성된다 | [STATUS.md](../STATUS.md) "측정 결과" |
| 체력이 모두 100이라 범위 피해로 죽는 자리가 일정하다 | [measurement.md](../Guides/measurement.md) "확정값"의 오브 피해 범위 행. 시체 고리는 사용자가 화면에서 본 것이다 |

## 결정

1. 장면은 옛 평지 시나리오다. 건물, 방향장, 시야 검사 저격, 0\~30m 발, 비켜 가기, 캡슐 콜리전, 부위 판정, 래그돌을 계획에서 뺀다. 저격 구간과 대형 예약 발은 옛 확정값 그대로다.
2. 시나리오에서 바꾸는 것은 하나다. 미니언의 체력을 개체마다 시드에서 정해 다르게 준다. 오브 둘레에 시체가 같은 반지름의 고리로 쌓이지 않게 하려는 것이다. 값은 표로 보고해 사용자가 확정하고, 총괄 묶음이 전 단계를 이 값으로 다시 잰다.
3. 목표 사양은 호드 총수 1만(잠정), 60fps다. 주 지표는 목표 총수에서의 프레임 시간이고 60fps를 지키는 최대 N은 보조다(ADR-0008의 결정 2, 3을 잇는다).
4. 사다리는 여덟 단계다: 액터 기준선, 로직을 Mass로, ISM + VAT, 근거리 액터 + 애니 예산, Simulation LOD + 엔티티 풀, ISKM + 고정 바운드, Niagara 배경 무리, 품질 올리기.
5. 사다리와 함께 빼 보기 표를 잰다. 최종 구성에서 기법 하나만 뺀 실행이다. 이점은 프레임 시간, 같은 프레임에서의 품질(액터 수, 전환 점수), 화면 중 하나로 인정한다. 재서 이점이 없는 기법은 구현을 고쳐 다시 재고, 그래도 없으면 최종 구성에서 빼고 경위로만 남긴다.
6. 공개 자료(글, README)의 수치와 근거는 총괄 묶음 `Full1`에서만 만든다. 그전의 묶음은 설계 판단의 참고로만 쓴다.
7. 글에는 한계 대신 프로젝트의 목적을 적는다.
8. 글에 넣는 GIF는 러너가 자동 촬영한다(ADR-0008의 결정 6을 잇는다).

세부는 [plan.md](../plan.md) "품질 계획"에 있다.

## 고려한 대안

| 대안 | 버린 이유 |
| --- | --- |
| ADR-0008대로 게임 장면을 끝까지 구현한다 | 건물, 방향장, 비켜 가기, 래그돌이 주제(하이드레이션과 품질)보다 커진다. 사용자가 과하다고 판단했다 |
| 평지에 캡슐 콜리전만 기준으로 켠다 | 액터가 없는 단계와 조건이 달라져 사다리를 잇기 어렵다. 하위 실험 한 점으로 남긴다 |
| 평지에 가까운 개체만 비켜 가기까지 켠다 | 프레임 +10.6ms(2만 P1)의 원인을 모르고 주제가 비켜 가기로 흩어진다 |
| Simulation LOD, ISKM, Niagara 배경 무리를 사다리에서 뺀다 | 사용자는 품질을 확보해 나가는 방향으로 셋을 가져가기로 했다. 대신 이점을 측정으로 보여야 한다(결정 5) |
| 사다리만 재거나 빼 보기 표만 잰다 | 사다리는 도달한 순서를, 빼 보기 표는 최종 구성에서 각 기법이 지키는 것을 보인다. 사용자가 둘 다 쓰기로 했다 |
| 프레임 시간만 이점으로 인정한다 | 하이드레이션과 Niagara 배경 무리처럼 품질을 사는 기법은 정의상 탈락한다 |

## 결과

- 승인되면 ADR-0008은 "대체됨"이 된다. "ADR 이전의 결정" 표의 "AI 범위"와 "오브"는 원래 내용이 다시 유효하다.
- 체력이 바뀌므로 옛 묶음과 수치를 잇지 않는다. 총괄 묶음이 전 단계를 한 번에 다시 재므로 따로 새 기준선 마일스톤을 두지 않는다.
- Niagara 배경 무리는 만든 적이 없어 비용과 200m 경계의 모습을 모른다. Simulation LOD와 ISKM의 이점은 2만에서 잰 참고값만 있다. 목표 총수에서 이점이 나오는지는 재 봐야 안다.
- 실행에서 확인한 것은 Q1부터 덧붙인다.

# ADR-0021 단계 8의 전환 거리를 40m에서 35m으로 낮춘다

- 상태: 제안됨(코디네이터 초안. 사용자가 2026-11-16 채팅에서 값 35m을 골랐다. [ADR-0019](0019-step8-actor-cap-distance-and-fixed-skel-bounds.md) 결정 2의 전환 거리와 [ADR-0010](0010-final-representation-bands.md)의 액터 구간 0\~40m를 대체한다)
- 날짜: 2026-11-16

맵 밖 무리의 재생성 자리를 고친 뒤([ADR-0020](0020-far-stream-respawn-handoff.md)) 오브 둘레의 개체가 늘어 단계 8(최종 구성)의 프레임 p95가 판정을 넘었다. 코드 쪽 비용을 줄이고 방향 보간을 병렬 사본으로 바꿔도 0.16ms가 남는다. 단계 8은 번 것을 품질에 쓰는 단계라서, 쓰는 양을 새 장면에 맞춰 줄인다. 화면 안 전환 거리를 35m으로 낮추면 p95가 1.79ms 줄고 판정을 1.63ms 여유로 통과한다. 액터 상한 1,000, 80m 밖 그림자 끔, 고정 바운드는 그대로다.

## 맥락

| 사실 | 근거 |
| --- | --- |
| 판정은 "단계 8의 프레임 p95 중앙값 + 0.6ms ≤ 16.7ms"다 | ADR-0019 결정 3 |

| 수정을 켠 단계 8의 p95는 16.96ms였다. 코드 비용을 줄인 뒤 16.66ms, 방향 보간 병렬 사본을 켜면 16.46ms다 | 묶음 `V2M6Split`, `V2M6Cost`, `V2SmoothOri`(Test, 3회) |
| 병렬 사본을 단계 3부터 켠 빌드에서 단계 8은 전환 거리 40m에서 p50/p95 13.75/16.26ms다. 판정 값 16.86ms로 0.16ms 넘는다. 35m에서는 13.02/14.47ms다. 판정 값 15.07ms로 1.63ms 남는다. 세 실행의 범위가 겹치지 않는다 | 묶음 `V2Hyd35`(Test dc75f6a, 3회) |

| 사다리 단계 2\~7의 값은 상한 500, 전환 거리 30m다 | `Source/HordeOptLab/LabConfig.h` `FLabQuality::DefaultHydrateM` |

## 결정

1. 단계 8의 화면 안 전환 거리는 35m이다(`FLabQuality::FinalHydrateM`). 표현 구간은 액터 0\~35m(상한 1,000), ISKM 35\~80m 그림자 켬, ISKM 80\~200m 그림자 끔, 200m 밖 입자다.
2. 액터 상한 1,000, 80m 밖 인스턴스 그림자 끔, 고정 바운드(배율 1.1), 판정식은 ADR-0019 그대로다.
3. 단계 2\~7의 값(상한 500, 30m)은 바꾸지 않는다. 단계 7→8은 여전히 품질을 올리는 단계다(30m → 35m, 500 → 1,000).

## 고려한 대안

| 대안 | 버린 이유 |
| --- | --- |
| A. 40m를 그대로 두고 판정 여유 0.6ms를 줄인다 | p95 16.26ms는 16.7ms 안이지만 여유가 0.44ms다. 긴 실행(+0.6ms)이 나오면 넘는다 |
| B. 39m, 38m, 37m을 재서 가장 큰 통과 값을 고른다 | 1m의 효과(0.36ms)가 세 실행의 p95 범위와 묶음 사이의 차(0.2ms)에 가까워 1m 단위로 가르지 못한다. 37m은 재지 않았고 기울기로 보면 여유가 약 0.9ms다 |
| C. 액터 상한을 낮춘다 | 40m에서 액터 최대가 825개라 상한 1,000에 닿지 않는다. 800 아래로 내리면 상한에 걸린 프레임에서 가까운 개체가 액터가 되지 못한다 |
| D. 유입 수를 낮춰 초당 사망을 ADR-0020 이전으로 되돌린다 | 사용자가 승인한 새 장면 값과 시나리오 고정값을 다시 바꾼다 |
| E. 80m 그림자 거리나 애니 예산을 낮춘다 | 넘는 것은 게임 스레드다. GPU는 약 6.2ms로 여유가 있다 |
| F. 35m으로 낮추고 남는 예산을 다른 품질에 쓴다 | 한 번에 두 값을 바꾸게 되고 묶음이 더 필요하다 |

## 결과

- 단계 8의 판정 여유가 1.63ms다(14.47ms, `V2Hyd35`). 총괄 묶음의 값으로 다시 확인한다.
- 35\~40m의 개체 평균 77개가 액터 대신 그림자를 켠 ISKM으로 보인다. 이 구간의 화면 차이(자세, 전환 순간)는 스크린샷이나 영상으로 보지 않았다.
- 품질 지표 `coverhyd`의 기준 거리가 35m이 된다. 40m 때의 값과 견주지 않는다.
- 다시 볼 조건: 게임 스레드 일이 줄어 여유가 2ms를 넘을 때 37\~40m를 다시 잰다.

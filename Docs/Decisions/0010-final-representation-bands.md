# ADR-0010 최종 구성의 표현을 거리 네 구간으로 나눈다

- 상태: 승인됨(2026-11-12 채팅에서 사용자가 승인)
- 날짜: 2026-11-12

최종 구성 `q4final`(사다리 8단계)의 화면 안 표현을 카메라 거리로 네 구간에 나눈다. 0\~40m는 액터(상한 1,000), 40\~80m는 ISKM에 그림자 켬, 80\~200m는 ISKM에 그림자 끔, 200m 밖은 엔티티 구동 입자([ADR-0011](0011-entity-driven-crowd-particles.md))다. 사다리 4\~7단계는 액터 0\~30m(상한 500), 그림자 켬 그대로다. 액터 구간을 밴드 끝 79m까지 늘렸던 Q4의 값을 40m로 줄인 것은, 79m에서는 애니 예산이 대형 액터 갱신의 0.66을 건너뛰어 액터가 ISKM보다 덜 부드러울 수 있기 때문이다.

## 맥락

[ADR-0009](0009-flat-scenario-quality-by-distance.md)의 사다리 8단계 "품질 올리기"는 목표 사양 안에서 액터 상한과 액터로 바뀌는 거리를 올려 최종 구성을 정하는 단계다. 값은 Q4에서 한 번 정했고(자율 결정 D11) 사용자가 돌아와 다시 정했다(D18, D19).

| 사실 | 근거 |
| --- | --- |
| 1만 P1 프레임 p95는 액터 500/30m 10.60ms, 1,000/50m 11.06ms, 1,000/70m 11.79ms, 1,000/79m 11.98ms다. P2는 어느 구성이나 5.46\~5.47ms다 | 마일스톤 묶음 Q4(Test 패키지 652cee4), `Measurements/Q4/summary.csv`, [Worklog/Q4.md](../Worklog/Q4.md) |
| 대형 액터의 애니 갱신 건너뜀 비율은 30m 0, 40m 0.03\~0.07, 50m 0.25\~0.31, 70m 0.63, 79m 0.66이다 | 같은 묶음. 예행 `Reh2`(10초 1회)의 40m 값은 0.055다([Worklog/Q5.md](../Worklog/Q5.md)) |
| 1만에서 액터 수는 상한 1,000에 닿지 않는다(79m에서 최대 786) | 같은 묶음 |
| 미니언 그림자는 켬이 확정값이었고 80m 밖 그림자의 비용은 잰 적이 없다 | [measurement.md](../Guides/measurement.md) "확정값" |
| 하이드레이션 액터의 캡슐 콜리전은 끔이 사용자 결정이었으나 코드에서는 켜져 있었다. 2b202fc에서 기본을 껐다(1만 P1 참고로 프레임 p95 −1.69ms) | 자율 결정 D15, [Worklog/Q5.md](../Worklog/Q5.md) "1b단위" |

## 결정

1. `q4final`의 화면 안 전환 거리는 40m, 액터 상한은 1,000이다(`LabConfig.h`의 `Q4FinalHydrateM`, `Q4FinalActorCap`). 화면 밖 전환 거리 15m는 그대로다.
2. 40\~80m(표현 LOD Medium)는 ISKM에 그림자를 켜고, 80\~200m(Low)는 ISKM에 그림자를 끈다(`-LabFarShadow=0`). 200m 밖 엔티티 구동 입자의 그림자도 같은 스위치를 따른다.
3. 사다리 1\~7단계는 바꾸지 않는다(액터 0\~30m, 상한 500, 그림자 켬). 8단계가 더하는 것은 액터 구간과 상한, 원거리 그림자 끔이다.
4. 원거리 그림자 끔의 값은 빼 보기 행 `A8-farshadow`(다시 켬)로 `Full1`에서 잰다. 이점이 보이지 않으면 [ADR-0009](0009-flat-scenario-quality-by-distance.md) 결정 5에 따라 뺀다.
5. 하이드레이션 액터의 캡슐 콜리전은 끈 채로 잰다. 켬은 하위 실험 `S8-col`이다.
6. 목표 총수는 1만, 프레임 p95의 여유 기준은 13.3ms(20%)로 두고 `Full1`에서 확정한다(Q4 묶음의 최종 구성 P1 프레임 p95: 5k 8.41ms, 1만 11.98ms, 2만 17.43ms).

## 고려한 대안

| 대안 | 버린 이유 |
| --- | --- |
| 액터 구간 79m(Q4의 값, D11) | 13.3ms 안에서 액터 수는 가장 많지만(709개) 대형 액터 갱신의 0.66을 건너뛴다. 세 프레임에 한 번꼴로만 포즈가 바뀌는 액터는 매 프레임 GPU 애니메이션인 ISKM보다 덜 부드러울 수 있다 |
| 액터 구간 50m, 70m | 건너뜀 비율이 0.25\~0.31, 0.63이다. 40m는 0.03\~0.07이다 |
| 기준 그대로(500, 30m) | 번 프레임을 품질에 쓰지 않는다. 사다리 8단계가 없어진다 |
| 40\~80m에 저품질 액터 | M3 하위 실험에서 이득이 약 0.45ms였고 URO로 움직임이 끊긴다 |
| 80\~200m를 VAT로 | 고정 바운드를 넣은 뒤 ISKM이 프레임 p50 0.36ms 낮았다(고정 바운드 묶음, 2종 20k P1) |
| 그림자를 모든 거리에서 켬 | 80m 밖 미니언은 화면에서 작다. 비용을 재지 않았으므로 스위치로 두고 빼 보기 행으로 잰다 |
| 목표 총수 2만 또는 5k | 2만은 최종 구성이 16.7ms를 넘는다. 5k는 여유가 4.9ms 남아 사다리 앞 단계가 구별되지 않을 수 있다 |

## 결과

- 사용자 확정값 둘이 바뀌었다: 미니언 그림자(최종 구성의 80m 밖에서 끔), 최종 구성의 액터 구간(40m). [measurement.md](../Guides/measurement.md) "품질 계획에서 바뀌는 값"에 적혀 있다.
- Q4 묶음의 최종 구성 수치는 79m와 콜리전 켬의 값이라 `Full1`과 견주지 않는다.
- 40m의 건너뜀 수치는 콜리전을 끄기 전 묶음의 값이고 소형 액터는 잰 적이 없다.
- 실행에서 확인한 것은 `Full1` 뒤에 덧붙인다.

## 미룬 마일스톤

- **M6 나이아가라 배경 티어 — "나이아가라로 전부 그리면 안 되나".** 맵 끝 너머 지평선에 수십만 개의 개체를 나이아가라 GPU 시뮬레이션 + VAT 메시 렌더러로 분위기용으로만 그린다. Mass 밖, 상호작용 없음. 가치 있는 실험은 "같은 VAT 메시를 Mass ISM으로 그린 M2와 개체당 GPU 비용 비교"다. 비목표(VFX 제작)와 겹쳐 M5 뒤로 미뤘다(2026-11-06).
- **M4b StateTree + Signal.** plan.md M4의 선택 항목. 글 하나 분량이 안 나오면 여기로.
- **3종째 개체(원거리 미니언).** 종류 수가 아키타입·VAT 텍스처·ISM/ISKM 컴포넌트·트랙·액터 풀을 어떻게 늘리는지. 새 기준선이 필요하다.

## 잘라낸 실험

- **넉다운 상태**(피격 → 쓰러짐 → 기상 → 다시 접근). StateTree 전이 다양성용이었지만 쓰러진 개체가 밀도 분포와 전환 빈도를 바꾸는 시나리오 변수라 뺐다. 즉사만으로 전이(접근 → 피격 → 사망)는 충분하다.
- **Niagara Examples Pack으로 오브·저격 시각화.** 5.8 호환 확인과 라이선스 관리 비용. 구체와 디버그 라인으로 충분하다. 영상 품질이 필요해지면 그때.
- E1 부록: 프로세서 하나 vs 셋, 프래그먼트 크기. E2: `AnimationMinScreenSize` 효과. E3: `BudgetMs` 1/2/3 스윕, 풀 크기. E5: 애니 수 10/50/200 메모리 곡선, N 100k+.
- 저해상 액터 티어(AnimBP 없이 시퀀스만). 액터 ↔ ISM 두 단계로 시작한다.

## 선택 심화

- **현실성 검증(M5 뒤).** 경사와 장애물이 있는 지형 맵에서 M0 `full`과 최종 단계를 앵커 N {1k, 5k}로 한 번씩 재서 평지 결과와의 차이를 "참고"로 적는다. 평지는 액터(CharacterMovement 바닥·스텝 처리)와 Mass(높이 샘플링·장애물 회피) 양쪽을 조금씩 유리하게 본다. 아래 "장애물 링 + 플로우 필드"와 묶는다(2026-11-07 사용자 승인).

- 장애물 링 + 플로우 필드(목표 고정일 때 맵 전체 방향장을 한 번 계산).
- 공간 격자 기반 저격 대상 선택(지금은 결정적 해시).
- "통합 Mass"(액터 없는 근거리) 프로토타입과 하이드레이션 비교.
- Replication LOD 개념 — DS 실험실과의 접점. 구현하지 않는다.
- 소스 빌드가 필요한 엔진 패치(ISKM 트랙 해제 경로) — 재활용 우회가 안 될 때만.

## 다시 논의할 것

- 저격 발 수 늘리기(2026-11-08 사용자 제안, 재논의). 중·원거리 피격·사망이 자주 보여 M2\~M3 표현을 보여 주기 좋지만, 사망·재생성 비용이 단계별 차이를 묻을 수 있다. 시나리오 변경이라 모든 단계를 다시 재야 하므로 M3b "새 기준선"에서 함께 정한다.

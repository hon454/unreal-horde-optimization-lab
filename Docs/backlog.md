## 미룬 마일스톤

- **비주얼 퀄리티 되사기(2026-11-09 사용자 요청).** 최적화로 아낀 예산을 화질에 다시 쓴다: 개체 수 조정, 근거리 액터 상한·하이드레이션 거리 늘리기, 사망 래그돌 예산, 거리별 VAT 품질 단계, 그림자·LOD 설정 등. 같은 프레임 예산(16.7ms)에서 N과 화질을 어떻게 맞바꾸나를 보여 주는 실험으로 짠다. 래그돌·VFX 제작 자체는 비목표라 "예산과 비용"으로만 다룬다. 이때 근거리 부위 판정과 피직스 바디(판정용 피직스 애셋, Kinematic + QueryOnly, 래그돌 예산)를 어떻게 켤지 함께 논의한다(2026-11-09 사용자 요청, M3b부터 액터 캡슐 콜리전은 끈다). 위치는 M5 뒤 첫 항목(2026-11-09 사용자 결정): M4·M5가 비용 구조를 바꾸므로 최종 파이프라인 하나에서 한 번 잰다. M6 나이아가라보다 먼저.
- **M6 나이아가라 배경 티어 — "나이아가라로 전부 그리면 안 되나".** 맵 끝 너머 지평선에 수십만 개의 개체를 나이아가라 GPU 시뮬레이션 + VAT 메시 렌더러로 분위기용으로만 그린다. Mass 밖, 상호작용 없음. 가치 있는 실험은 "같은 VAT 메시를 Mass ISM으로 그린 M2와 개체당 GPU 비용 비교"다. 비목표(VFX 제작)와 겹쳐 M5 뒤로 미뤘다(2026-11-06).
- **M4b StateTree + Signal.** plan.md M4의 선택 항목. 글 하나 분량이 안 나오면 여기로.
- **3종째 개체(원거리 미니언).** 종류 수가 아키타입·VAT 텍스처·ISM/ISKM 컴포넌트·트랙·액터 풀을 어떻게 늘리는지. 새 기준선이 필요하다.

## 잘라낸 실험

- **넉다운 상태**(피격 → 쓰러짐 → 기상 → 다시 접근). StateTree 전이 다양성용이었지만 쓰러진 개체가 밀도 분포와 전환 빈도를 바꾸는 시나리오 변수라 뺐다. 즉사만으로 전이(접근 → 피격 → 사망)는 충분하다.
- **Niagara Examples Pack으로 오브·저격 시각화.** 5.8 호환 확인과 라이선스 관리 비용. 구체와 디버그 라인으로 충분하다. 영상 품질이 필요해지면 그때.
- E1 부록: 프로세서 하나 vs 셋, 프래그먼트 크기. E2: `AnimationMinScreenSize` 효과. E3: `BudgetMs` 1/2/3 스윕, 풀 크기. E5: 애니 수 10/50/200 메모리 곡선, N 100k+.
- 저해상 액터 티어(AnimBP 없이 시퀀스만). 액터 ↔ ISM 두 단계로 시작한다.

## 선택 심화

- **현실성 검증(M5 뒤).** 경사와 장애물이 있는 지형 맵에서 M0 `full`과 최종 단계를 앵커 N {1k, 5k}로 한 번씩 재서 평지 결과와의 차이를 "참고"로 적는다. 평지는 액터(CharacterMovement 바닥·스텝 처리)와 Mass(높이 샘플링·장애물 회피) 양쪽을 조금씩 유리하게 본다. 아래 "장애물 링 + 플로우 필드"와 묶는다(2026-11-07 사용자 승인).

- 장애물 링 + 플로우 필드(목표 고정일 때 맵 전체 방향장을 한 번 계산). 2026-11-09: M5 뒤 마일스톤으로 올리는 것을 검토 중(결정 7). 시나리오 변수라 새 기준선. 회피 비용은 M4 (c) 결과를 보고. Shabel의 ISM 11만 개 플로우 필드 데모가 현업 근거(talk-notes.md 31:39).
- 공간 격자 기반 저격 대상 선택(지금은 결정적 해시). 범위 피해·저격·ActorSync가 매 프레임 전 N을 순회한다(2026-11-09 점검). M4 뒤 실험.
- Lab 프로세서 그룹을 게임 스레드 밖으로(`OffGameThreadGroupNames`, City Sample `DefaultMass.ini:7`). M3b에서 그룹을 선언한 뒤 M4에서 시험.
- `m3visoff`: 화면 밖은 80m부터 안 그리기(Base Off 80m). E3b (8) 뒤 후보.
- 바닥 밴드 표시(결정 6, 2026-11-09): 개발 빌드 `-LabBandFloor`로 카메라 기준 30/80/200m 띠를 바닥 머티리얼(`CameraPosition` − `AbsoluteWorldPosition` XY 거리)로 그린다. 측정 빌드는 기본 바닥. 대안 `DrawDebugCircle`.
- "통합 Mass"(액터 없는 근거리) 프로토타입과 하이드레이션 비교.
- 거리별 VAT 품질 단계: 가까운 쪽은 상세 메시 + 본 영향 4, 먼 쪽은 간략 메시 + 본 영향 1로 따로 굽는다(2026-11-08 M2 결정 1의 D안, 변수 둘이라 M2에서 뺐다).
- 근거리 부위 판정 비용(2026-11-09 사용자 질문에서). 하이드레이션 액터에 판정용 피직스 애셋(뼈마다 QueryOnly 바디)을 켜고 트레이스 피격을 엔티티 사건으로 넘길 때의 비용을, E3 (6)의 캡슐 하나(20k 1.55ms)와 비교한다. 무기 전투는 비목표라 판정과 비용만 다룬다. 원본 피직스 애셋은 Simulated라 Kinematic·QueryOnly로 바꿔야 한다(engine-notes.md 9절).
- 근거리 사망 래그돌 예산(2026-11-09 사용자 질문에서). 래그돌 동시 상한, 멈춘 뒤 정지 포즈로 굳히기·정리 규칙이 하이드레이션 액터 상한(500)과 어떻게 다투는지. 원거리 사망은 VAT 그대로.
- Replication LOD 개념 — DS 실험실과의 접점. 구현하지 않는다.
- 소스 빌드가 필요한 엔진 패치(ISKM 트랙 해제 경로) — 재활용 우회가 안 될 때만.

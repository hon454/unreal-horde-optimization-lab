# V2 글 00\~07 팩트체크

글 여덟 편(`Posts/NN-*/README.md`, 그림의 대체 텍스트와 SVG 글자, `measurements.md`)과 루트 `README.md`, `Posts/README.md`의 사실 주장을 근거와 대조했다. 글은 고치지 않았다. 반영 여부는 사용자가 정한다.

- 근거: 총괄 묶음 `Full4`(패키지 de0e21b)의 `summary.csv`, `runs.csv`, `equivalence.csv`, 참고 묶음 `Pool2`의 `timeline.csv`, `summary.csv`, 조건 표 `Scripts/full-conditions.json`, 측정 빌드 de0e21b의 `Source/`, 소스 빌드 엔진 `Engine/Source`, `Engine/Plugins`.
- 차이 판정 규칙: 중앙값의 변화가 두 조건의 범위 가운데 큰 쪽보다 클 때만 차이다. `Full4`에서 0.5ms 아래의 차이는 범위를 넘어도 "구별되지 않았다"로만 쓴다([measurement.md](../Guides/measurement.md) "차이 판정"). `Pool2`는 조건마다 한 번이라 차이 판정에 쓰지 않는다(같은 문서 "엔티티 풀 묶음 규약").
- 방법: 글마다 하위 에이전트 하나가 읽기만 하며 대조했다. 이 문서에 실은 "틀림"과 주요 "부정확"은 이 세션이 근거 파일을 직접 열어 다시 확인했다(아래 "다시 확인한 것").
- 맞은 주장은 싣지 않는다. 판정은 틀림 / 부정확 / 근거 없음 / 미확인이다.

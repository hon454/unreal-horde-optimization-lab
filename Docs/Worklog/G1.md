# G1 게임 장면

## 2026-11-11 설계 값 확정

코디네이터가 설계 값 표(건물, 방향장, 저격, 비켜 가기, 확인 항목)를 채팅에 냈고 사용자가 그대로 확정했다. 값은 [measurement.md](../Guides/measurement.md) "게임 장면 확정값(G1)"에 있다.

확인하지 않은 것:

- 건물 약 44채, 덮는 면적 약 30%는 계산값이다.
- 액터가 지금 어떤 코드로 이동하는지, RVO 설정값은 소스를 보지 않고 정했다.
- 2m 칸이 골목 모퉁이에서 자연스러운지, 건물이 P1 화면을 얼마나 가리는지는 돌려 봐야 안다.

구현은 코드 세션이 맡고 아래에 절을 덧붙인다.

## 2026-11-11 중단과 폐기

사용자가 구현을 멈추게 했고, 게임 장면 계획 자체를 버렸다([ADR-0009](../Decisions/0009-flat-scenario-quality-by-distance.md)). 코드 세션의 변경(소스 16개 수정, `LabScene.cpp`·`LabScene.h` 추가)은 커밋하지 않은 채 사용자 지시로 버렸다. 코드는 태그 `M5` 뒤의 평지 상태다. `Binaries/`는 버린 코드로 빌드된 것이라 다음 개발 실행 전에 다시 빌드한다.

코드 세션이 멈추며 보고한 것(코디네이터가 코드나 실행 결과로 확인하지 않았다): 차선을 넣기 전의 단일 경로 구현에서 전 단계가 작은 규모 실행을 통과했다. 액터 1만은 끝까지 돌았고 개발 빌드에서 프레임당 약 1.3초였다. P1에서 그려지는 개체 수는 평지의 91.7%였다. 차선 여러 벌 방향장(사용자가 갈라져 나온 세션에서 고른 안)을 넣은 뒤의 결과는 읽지 않았다.

남긴 것: 코드 세션이 엔진 소스에서 확인한 사실은 [engine-notes.md](../Reference/engine-notes.md) 16절에 남겼다(엔진 조향의 목표점, 엔진 비켜 가기와 LOD 태그, CharacterMovement RVO 기본값). 위 "설계 값 확정" 절이 가리키는 measurement.md "게임 장면 확정값(G1)"은 지웠다(git 3e54c37).

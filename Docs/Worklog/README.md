# 작업 기록

마일스톤마다 `M<N>.md` 하나(품질 계획은 `Q<N>.md`. `G1.md`는 버린 게임 장면 계획의 기록이다). 끝낸 작업의 경위, 실패한 실행과 원인, 버린 시도를 날짜순으로 덧붙인다. 지난 항목은 고치지 않는다. 세션을 시작할 때 읽지 않고, 라벨이나 날짜로 검색만 한다. STATUS.md에서 끝난 항목을 옮길 때 원문 그대로 옮긴다.

제목 형식: `## YYYY-MM-DD 한 일 (실행 라벨)`
- [Q7.md](Q7.md): 애니메이션 예산 값을 다시 정하는 작업(`-LabBudgetMs=`, 오브 상태 경합 수정, 건너뜀 지표, 참고 묶음 `Budget1`, 총괄 묶음 `Full3`).
- [Q8.md](Q8.md): 매니저 변형(`-LabStage=M1 -LabVariant=manager`)과 참고 묶음 `Mgr1`.
- [Posts.md](Posts.md): 글 작업 기록(글마다 한 절).
- [CodeTour.md](CodeTour.md): 최종 구성 코드 투어(`Docs/Guides/code-tour.md`)를 쓴 기록.
- [Setup.md](Setup.md): 클론 뒤 에셋 복구 스크립트(`Scripts/restore-assets.ps1`)와 준비 가이드(`Docs/Guides/setup.md`)를 만든 기록.
